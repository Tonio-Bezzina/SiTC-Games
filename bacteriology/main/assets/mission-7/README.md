# Mission 7 asset set

Transparent PNG artwork for the guided bacterial-smear preparation scene. Slide states share a 1254 × 1254 canvas and CSS rectangle. The 1 µL loop states, burner states, and colony overlays also use matching rectangles so state changes do not shift.

The lit flame, selected-colony mark, smear path, airflow, arrows, and heat-fix path are rendered as responsive CSS/SVG interaction layers. This keeps instructional graphics separate from the scientific artwork.
