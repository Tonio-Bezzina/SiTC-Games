# Mission 9 microscopy assets

This pack supplies the layered microscope scene, slide-placement states, binocular transition, focus states, and four comparison fields used by Mission 9 of Bacteriology Journey.

All production PNGs use a 1254 × 1254 canvas. The microscope, stage, slide, and eyepiece assets preserve transparency where required. The four microscopy fields are deliberately presented at the same scale and framing so that colour, shape, and arrangement—not image treatment—determine the answer.

The completed Gram-stained slide is derived from Mission 8. `microscope-focus-soft.png` is an aligned blurred transition state of `microscope-focus-sharp.png`; it is not an additional answer choice.

Correct scientific clue: purple cocci in chains. Species-level identification remains reserved for Mission 10.
