# Mission 10 MALDI-TOF assets

This pack supplies the new equipment and aligned visual states required by `MISSION-10-DESIGN.md`.

All production PNGs use a 1254 × 1254 transparent canvas and a polished, lightly stylised laboratory-realism aesthetic. The pipette, target plate and MALDI-TOF state pairs/groups are aligned so the game can swap images without moving the object.

Existing laboratory, culture and loop artwork is reused from Missions 2 and 7. No additional Mission 10 raster asset is required by the implementation.

The images were generated with the built-in image-generation tool. Prompts specified transparent game cutouts, white/charcoal/cobalt laboratory equipment, soft studio lighting, complete silhouettes, no embedded text, and no branding or watermarks. State-edit prompts changed only the liquid, occupied target spot, or instrument door/lighting while preserving alignment.
