# Haematology Game Queries

## Questions asked before development

### 1. Repository inspection

**Question:** May the existing SiTC repository be inspected only to determine its folder structure, integration pattern, and hub connection, while continuing to use `HAEMATOLOGY_GAME.md` as the sole source for the game's content and design requirements?

**Answer:** Yes.

**Decision:** Existing repository files may be inspected only for technical placement and integration. They are not sources for the haematology game's content or design requirements.

### 2. Challenge-level cell images

**Question:** Should the Challenge-level realistic cells be created from the descriptions in `HAEMATOLOGY_GAME.md`, or will approved realistic images be supplied?

**Answer:** Create the cells from the descriptions.

**Decision:** Create the required Challenge-level cell assets using only the descriptions in `HAEMATOLOGY_GAME.md`.

### 3. Wording approval

**Question:** Is the wording currently in `HAEMATOLOGY_GAME.md` approved for the first implementation, pending later educational review?

**Answer:** Yes, exactly.

**Decision:** Use the current wording exactly as written for the first implementation.

### 4. Git branch

**Question:** Should the work be pushed directly to the repository's current branch, or developed on a new `codex/haematology-game` branch?

**Answer:** Create a new branch.

**Decision:** Develop and push the game on the `codex/haematology-game` branch.
